Binding constraints for every task (AGENTS.md, FORK.md, operator memory):
- No conflict resolution changes Helios policy, contracts, recipes or the core format beyond the Muse Glimmer number (10 → 11). Every resolution carries each side's code as it runs today, on upstream's structure (Inductor-planned temporaries, #291 body quantization, #250 embedding binding).
- No resolution designs a new kernel, fusion, stream or scratch mechanism. A hunk that cannot be carried without one stops the task and becomes a discovery for the operator.
- `main` only fast-forwards and is never merged into or landed on.
- Images are built, and exports and serving run, in the container from a committed ref (`~/LocalApps/vllm-env/build/flare-ignition/build.sh`), never with the host toolchain.
- No environment-variable switches.
- GPU 0 is the owner's console instance: the owner stops and starts it, and it is never touched with `docker stop`.
- Heavy commands run one file at a time under a 14 GiB watchdog on the real PID, and processes are stopped only by PID.
- Replayed commits keep their historical `Design-Signed-Off-By` trailers and are continued with `git -c core.hooksPath=/dev/null rebase --continue`. Every commit this change writes runs with the hook on, acknowledged against `docs/design-review.md` digest `ed22`, and is reviewed against `.agents/skills/repo-prose/SKILL.md`.
- No audit reports, receipts or hash inventories.
