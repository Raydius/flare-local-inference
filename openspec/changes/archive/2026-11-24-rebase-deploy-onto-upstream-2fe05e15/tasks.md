# Tasks

Binding constraints for every task (AGENTS.md, FORK.md, this change's design.md):
- `main` only fast-forwards and is never merged into or landed on. Core `base/current`, `patch/00`, `01`, `03`, `06`, `07` and `deploy` stay on their backups until task 5.3; all work before that happens on `split/*` copies and scratch worktrees under `~/models/.cache/rebase-2fe05e15/`.
- No conflict resolution changes Helios policy, a recipe, a contract or the core format beyond what upstream brings. Every resolution carries each side's code as it runs today, on upstream's structure. "Union" is additive hunks only.
- No resolution designs a new kernel, fusion, stream or scratch mechanism, and no new captured-graph operation family. A hunk that needs one stops the task and becomes a `discovery:` for the operator.
- No environment-variable switches; no eager serving, runtime compilation or graph recapture; capacities outside the prepared set are refused, not fallen back on.
- Replayed commits continue with `git -c core.hooksPath=/dev/null rebase --continue` and keep their historical `Design-Signed-Off-By` trailers. Every core commit this change writes runs with the hook on, is acknowledged against `docs/design-review.md` digest `eb2f`, and is reviewed against `/home/rjdollete/dev/flare-local-inference/.agents/skills/repo-prose/SKILL.md`. Recipe-fork commits follow that repo's own hooks (`.githooks/`).
- Images are built, and exports and serving run, in the container from committed refs (vllm-env `build/flare-ignition/build.sh`), never with the host toolchain. Heavy commands run one file at a time under a 14 GiB watchdog on the real PID (`systemd-run --user --scope -p MemoryMax=14G`); processes are stopped only by PID.
- GPU 0 is the owner's console instance: never touched with `docker stop`; GPU 1 is the gate card.
- Re-export and served re-measurement of the console's entries are out of scope; `flare inspect`, dry-run planning and serving an existing core are in.
- Baseline comparisons are by test id; a fork-only test file must pass outright; every gate path is checked to exist before it runs.
- No audit reports, receipts or hash inventories.
