# Debug — Nemotron Bolt package serves wrong text and "prepared model reported device error 1"

## Symptoms

- `flare run` loads package `gb202-tp1-202610291532` (exported 2026-10-29 on `local/flare-ignition:24ea1694`, FlashInfer `da45a722`) and starts serving — evidence: `~/models/.cache/dflash2-probe/keep/serve-hd.log` "Start server.  http://0.0.0.0:8111 · 262144 tokens/request"
- "Say hi" at temperature 0 with thinking disabled returns text unrelated to the prompt — evidence: content `'\n### Step 1: Calculate the distribution of standard deviations for all components…'` (serve-debug runs r1a, r1b; same text in `serve-nohd.log` session)
- "What is the capital of France? Answer in one word." returns HTTP 500 — evidence: `{"error":{"type":"server_error","message":"prepared model reported device error 1",…}}`; server log `stage=generation code=server_error message="prepared model reported device error 1"`
- A code prompt sent after the device error returns unrelated text that differs between runs — evidence: r1a `'To calculate the risk-reward ratio…'`, r1b `'To calculate the flow rate of air from the compressor…'`
- With thinking left on, "Say hi" put unrelated text in reasoning — evidence: `serve-hd.log` session reply `"reasoning_content":"Bally Malta, Inc. v."`
- Same faults with `--history-drafts` (`flare_history_drafts_enabled 1`) and without it (`flare_history_drafts_enabled 0`) — evidence: `keep/serve-hd.log`, `keep/serve-nohd.log`
- With speculation off, the first request on a server returns no error but can still answer wrongly — evidence: `ORDER=france-first repro.sh h2 --mtp-draft-tokens 0` France -> `'Buttermilk'`; `repro.sh h1 --mtp-draft-tokens 0` "Say hi" -> `'Hello there! How can I help you today?'`
- Faults are independent of KV cache size — evidence: 66.9 GiB cache (`serve-hd.log`) and 11.9 GiB cache under `--memory-limit 40G` (r1a, r1b)
